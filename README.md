## Project overview
A responsive registration form built with HTML5, Bootstrap 5, custom CSS, and JavaScript. When the user submits valid information, a Bootstrap modal displays a review of the entered details before the user confirms.

## Features
- Responsive layout using Bootstrap 5
- Full name, email, gender, contact number, username, password, and confirm password fields
- Required-field, email, contact-number, username-length, and password validation
- Confirmation modal with a summary of the entered information
- Go Back to Edit and Confirm Submission actions
- Password is intentionally masked and is not displayed in the review modal
- No information is transmitted to a server; confirmation is a front-end demonstration

## Files
- `index.html` — page structure and Bootstrap modal
- `style.css` — custom responsive styling
- `script.js` — validation and modal interactions

## How to run
1. Extract the ZIP file.
2. Open the `RegalaMadel_BSIS2A_Activity1` folder.
3. Double-click `index.html` to open it in a modern browser.
4. An internet connection is required to load Bootstrap and Google Fonts from their CDNs.

## Test the form
1. Fill in all required fields.
2. Use a valid email address and contact number.
3. Enter a password with at least 8 characters and repeat it correctly.
4. Select **Review Information**.
5. Check the information in the confirmation modal.
6. Select **Go Back to Edit** to make changes, or **Confirm Submission** to see the success message.
